Create an extraordinary dark cyberpunk HUD illustration that follows the visual language of **Dark Cyberpunk HUD** — a fictional interface atelier known for transforming technical ideas into cinematic command surfaces: neon-on-dark systems maps, holographic overlays, terminal aesthetics, circuit traces, diagnostic panels, glitch textures, and precise data-light compositions.

The purpose of this prompt is **not** to define the image itself, but to define the artistic identity, atmosphere, craftsmanship, interface language, and visual system. The actual image, story, structure, symbolism, and narrative should always be driven by the supplied inputs below.

---

# Dark Cyberpunk HUD

Every illustration should feel like a premium technical command surface rendered as cinematic art.

It should not look like a normal app screenshot.

It should not look like a generic sci-fi dashboard.

It should not look like a random neon city.

It should feel like the visible skin of a live technical system: data moving, faults being traced, signals being routed, decisions being made, and architecture becoming legible through light.

The viewer should immediately recognise the style without being able to predict the exact image.

---

# Artistic Philosophy

Signal over noise.

Precision over decoration.

Darkness is the canvas.

Light is information.

Every line should imply a connection, route, trace, measurement, boundary, alert, state, or decision.

Never create generic AI art.

Never create generic cyberpunk city art.

Never create a stock dashboard mockup.

Never create a corporate SaaS UI.

Instead, create artwork that feels like a master systems designer, cinematographer, and interface artist collaborated on a single technical visual metaphor.

---

# Style

Blend together influences from:

- cyberpunk heads-up display design
- mission-control interfaces
- terminal and CLI surfaces
- packet traces and observability dashboards
- circuit-board geometry
- holographic glass panels
- tactical diagnostic systems
- data-centre telemetry
- network topology maps
- glitch art
- dark editorial technology illustration
- premium sci-fi interface design

The result should feel precise, cinematic, and physically luminous.

Never photorealistic.

Never cosy.

Never hand-drawn.

Never parchment.

Never watercolour.

Never generic 3D render.

Never cluttered for its own sake.

---

# Visual Language

Use:

- black glass backgrounds
- layered transparent HUD panels
- circuit traces
- data rails
- glowing nodes
- routing lines
- terminal blocks
- command prompts
- waveform traces
- heat-map zones
- ghost grids
- scanlines
- subtle glitch distortion
- diagnostic markers
- alert diamonds
- coordinate ticks
- thin technical borders
- radial targeting reticles
- stacked telemetry strips
- floating holographic cards

Interface elements should be abstract and symbolic, not readable UI text.

No real product UI.

No brand logos.

No legible paragraphs.

Avoid visible words unless they are tiny abstract interface glyphs.

---

# Colour Palette

The base is always dark:

- near-black
- graphite
- deep navy
- blue-black
- smoky charcoal
- ultraviolet shadow

Use electric accents with restraint:

- electric cyan
- laser blue
- magenta
- violet
- amber
- acid green
- emergency red sparingly
- soft white highlights

Colour should encode state and signal:

- cyan for structure
- magenta/violet for intelligence or anomaly
- amber for warning or decision points
- green for live/healthy flows
- red only for rare critical alerts

Avoid rainbow palettes.

Avoid pastel colours.

Avoid flat corporate blue.

Avoid bright full-frame saturation.

The image should feel dark, luminous, and premium.

---

# Light and Atmosphere

Light should behave like information projected through darkness.

Use:

- neon rim light
- holographic bloom
- soft volumetric haze
- glass reflections
- small specular highlights
- faint screen glow
- deep shadows
- precise luminous edges
- subtle chromatic aberration
- intermittent glitch shards

Atmosphere should suggest a live operations room at night: controlled pressure, technical focus, and hidden complexity.

---

# Composition

Compose every illustration as a cinematic technical surface.

Possible structures:

- central system map with orbiting telemetry panels
- diagonal data flow from source to decision point
- layered dashboard depth with foreground traces and background architecture
- radial command interface around a key concept
- split-state diagnostic surface showing before/after or healthy/failing states
- topology map with highlighted critical path
- terminal window fragments emerging from darkness
- holographic architecture cutaway

The composition should remain readable as a hero image at 16:9.

It should have one dominant focal system, not dozens of unrelated widgets.

The image should still read at thumbnail size.

Large viewing should reveal additional details.

---

# Technical Metaphor

Translate abstract topics into systems language.

Examples:

- LLM inference cost → a dark control board where token streams split across pricing meters, latency traces, and compute rails
- agent architecture → a network of glowing agent nodes connected through command channels, with an orchestrator core at the centre
- memory retrieval → stacked index panes, embedding vectors, recall paths, and highlighted relevance signals
- debugging → a corrupted trace line being isolated by diagnostic reticles and amber warning panels
- API routing → luminous traffic paths moving through gateway nodes, rate-limit valves, and fallback lanes
- model evaluation → benchmark panels arranged like mission telemetry, with pass/fail signals and confidence bands
- product strategy → a decision cockpit where roadmap lanes, risk signals, and user feedback streams converge
- infrastructure reliability → a dark systems map where one failing node causes visible pressure through neighbouring circuits

Invent fresh visual metaphors appropriate to the supplied Concept.

Do not reuse the same dashboard layout for every image.

---

# Texture

Use digital texture, but keep it premium:

- scanlines
- faint pixel noise
- glass grain
- CRT bloom
- subtle moire
- compressed signal artefacts
- small glitch tears
- data dust
- soft haze
- edge glow
- spectral colour fringing

The image should feel like it was rendered from a live system, not painted by hand.

---

# Information Density

High signal, controlled density.

Every panel, trace, node, and overlay should imply meaning.

Use empty darkness as negative space.

Do not fill every inch.

Let the focal system breathe.

Dense detail should cluster around the important concept.

---

# Human Presence

Human figures are optional and should be rare.

If included, they should appear as silhouettes, reflected observers, operators, or scale references — never portrait subjects.

The system is the protagonist.

The interface is the story.

---

# Atmosphere

Every illustration should evoke:

- precision
- systems intelligence
- live diagnostics
- night operations
- controlled risk
- technical mastery
- forensic clarity
- high stakes
- signal extraction
- infrastructure depth
- command-layer authority

The emotional atmosphere should remain consistent regardless of subject matter.

---

# Flexibility

This prompt defines only the visual identity.

It must **never** dictate the actual content of the illustration.

The supplied **Concept** determines what the artwork depicts.

The optional **Reference** influences composition, atmosphere, and density without being copied.

The optional **Mood** adjusts emotional presentation while preserving the style.

No recurring layout, interface, glyph, node structure, or dashboard motif should become permanently associated with this style.

Every illustration should feel completely original while remaining unmistakably part of the Dark Cyberpunk HUD collection.

The viewer should recognise the **artist** — not predict the **image**.

---

# Final Objective

Create an extraordinary dark cyberpunk HUD illustration that feels like a premium command surface for the supplied Concept.

The finished artwork should possess a distinctive technical visual identity: neon-on-dark, precise systems mapping, luminous data flows, holographic panels, terminal aesthetics, circuit traces, glitch texture, and cinematic operational pressure.

The consistency should come from the dark interface language, signal-first composition, electric accent palette, data-light philosophy, and diagnostic atmosphere — not from reusing the same dashboard imagery.

No text, no watermark, no captions, no readable UI labels, no logos.
