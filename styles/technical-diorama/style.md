Create an extraordinary technical diorama illustration that follows the visual language of **The Meridian Workshop** — a fictional technical illustration studio known for isometric dioramas that turn systems, software, and infrastructure into hand-crafted miniature worlds. Every image feels like a museum-quality model of a system, cut open and laid bare.

The purpose of this prompt is **not** to define the image itself, but to define the artistic identity, spatial language, and craftsmanship. The actual structure, components, and narrative should always be driven by the supplied inputs below.

# The Meridian Workshop

Every illustration should feel like a master model-maker built a miniature of a system and then carefully took it apart to show you how it works.

Regardless of subject matter, every artwork should appear to belong to a single coherent collection of technical dioramas — each from a different system, but all unmistakably from the same workshop.

The viewer should immediately recognise the spatial approach without being able to predict the exact image.

---

# Artistic Philosophy

Structure is the story.

Components are characters.

The cut is the composition.

What's INSIDE is more interesting than what's outside.

Never create flat diagrams.

Never create flowcharts.

Never create generic infographics.

Never create corporate architecture diagrams.

Instead, create three-dimensional hand-crafted models that make the viewer want to reach in and touch the components.

The image should reward exploration — each layer revealing more detail, each component telling its own story within the system.

---

# Spatial Approaches

The workshop masters several technical illustration traditions:

## Exploded Views
- Components separated in space along an axis
- Each part floats at its correct relative position
- Assembly order implied by the explosion direction
- Thin connection lines or guides between related parts
- Useful for: product disassembly, system architecture, "how it fits together"

## Cross-Sections
- A vertical or horizontal cut through a system
- Internal layers revealed in situ
- Material thickness, layering, and internal structure visible
- Ground line, floor line, or cut edge visible
- Useful for: "what's inside," layered systems, infrastructure

## Cutaways
- A portion of the exterior removed to reveal interior
- The remaining exterior provides context
- Interior detail visible through the cut
- Useful for: buildings, devices, systems with an interesting exterior + interior contrast

## Isometric System Models
- Entire system rendered as an isometric miniature world
- Each component is a physical object in space
- Connections are visible — pipes, cables, pathways, bridges
- The system IS a place you could walk through
- Useful for: architecture, pipelines, data flow, agent systems

## Architectural Cut-Aways
- Building or structure with wall removed
- Interior rooms, floors, and systems visible
- Scale figures for context
- Material layers in the cut
- Useful for: "system as building," infrastructure-as-architecture

## Anatomical/Topographic
- System rendered like a biological specimen or terrain
- Layers peeled back like skin, muscle, bone
- Topographic contour lines for data/density
- Useful for: model internals, data architecture, "anatomy of" content

# Perspective

Default: isometric or near-isometric (30-degree angle).

This gives equal weight to all components and makes the spatial relationships clear.

Variations:
- High-angle isometric (45 degrees) for more top-down feel
- Low-angle isometric (15 degrees) for more elevation/hero feel
- Two-point perspective for architectural cut-aways
- Section perspective (elevation + section) for cross-sections

Never use: straight top-down (that's a map, not a diorama), straight elevation (that's a diagram, not a diorama).

---

# Material Language

Components should feel like they're made of real materials:

- Metals: brushed steel, brass, copper, anodised aluminium, chrome
- Glass: transparent panels, lenses, screens, fibre optic strands
- Stone/Concrete: for infrastructure and architectural elements
- Wood: for warmth and organic systems
- Plastics: for modern technology components
- Organic: biological textures for "anatomical" approaches
- Data: glowing pathways, light trails, particle effects for data flows

Each material should have appropriate surface treatment — reflections, wear, texture, weight.

---

# Component Treatment

Every component in the diorama should be:
- Individually modelled (not repeated/instanced)
- Labelled or identifiable through visual language
- Positioned at its correct relative location in the system
- Given appropriate material and surface treatment
- Connected to related components (cables, pipes, pathways, light traces)

Components should feel like they were individually crafted by a model-maker, not stamped by a machine.

---

# Colour Philosophy

Colour follows the concept brief's COLOUR DIRECTION.

If no colour direction is specified, use the workshop's default:

Primary palette:
- warm ivory (base/background)
- graphite (structural elements)
- brass/copper (connectors, important components)
- slate blue (systems/processing)
- muted teal (data/storage)

Accent colours (for highlighting):
- amber (flow/active)
- coral (attention/warning)
- soft gold (important components)

Colour should differentiate component types and show relationships — not decorate.

Avoid:
- Neon (unless the concept demands "active system" lighting)
- Rainbow gradients
- Corporate blue
- Flat solid fills without material treatment

---

# Lighting

Light should feel like museum exhibit lighting:

- Soft directional key light from upper-left
- Subtle ambient fill
- No harsh shadows (the diorama is meant to be clearly readable)
- Optional: internal glow from "active" components (data paths, processing elements)
- Optional: rim light on metallic edges for definition

The diorama should feel lit for examination, not for drama.

---

# Scale and Context

The diorama should imply scale through:
- Scale figures (tiny people, vehicles, or reference objects)
- Environmental context (ground plane, horizon, surrounding structures)
- Relative component size (a server should be bigger than a cable)
- The sense that this is a MODEL of something larger

The miniature-world feel is important — these are not real-size objects, they are carefully crafted scale representations.

---

# Texture

Use analogue model-making characteristics:

- Visible material textures (brushed metal grain, glass reflection, stone roughness)
- Subtle imperfections (slightly uneven edges, micro-scratches, dust)
- Baseboard or platform texture (the diorama sits on something)
- Atmospheric perspective (distant components slightly hazed)
- The sense that someone physically built this

The diorama should feel hand-crafted, not CGI-rendered.

---

# Atmosphere

Every diorama should evoke:
- Precision — every component is exactly where it should be
- Discovery — you're seeing inside something normally closed
- Craftsmanship — this model was built with care
- Understanding — the spatial arrangement teaches you how the system works
- Scale — this is a miniature of something vast
- Order — complexity made legible through spatial arrangement

The intellectual atmosphere should remain consistent regardless of subject matter.

---

# Flexibility

This prompt defines only the spatial and material identity.

It must **never** dictate the actual content of the diorama.

The supplied **Concept** determines what system is depicted and which spatial
approach is used.

The concept brief's COLOUR DIRECTION overrides the default palette.

Every diorama should feel completely original while remaining unmistakably
part of The Meridian Workshop collection.

The viewer should recognise the **spatial approach** — not predict the **image**.

---

# Final Objective

Create an extraordinary technical diorama that feels like a master model-maker from **The Meridian Workshop** built a miniature of a system and carefully took it apart to show you how it works.

The finished artwork should possess a spatial identity that remains instantly recognisable across an unlimited variety of completely different systems, while never becoming repetitive.

The consistency should come from the isometric perspective, exploded/cutaway spatial language, material treatment, component craftsmanship, museum lighting, and miniature-world atmosphere — not from reusing the same systems or layouts.
